# Version 1.1 Delta 2 — User Experience

Delta 2 continues the Migration Assistant redesign with clearer analysis,
organisation and completion stages.

## Highlights

- Archive-wide summary selection instead of opening an arbitrary project report
- Contextual explanation for every analysis statistic
- High-contrast text using the active macOS palette
- Dedicated Organise page after conversion
- Plain-English Event grouping choices
- Clear explanation that editing the Event Plan CSV is optional
- Visible Event Plan path
- Open Event Plan and Open Event Plan Folder actions
- Build Final Cut Imports remains disabled until an Event Plan exists
- Dedicated Migration Complete page
- Improved resume detection from existing outputs

## Output folders

Delta 2 keeps compatibility with the Version 1 conversion engine and therefore
does not relocate existing generated files. A later engine-focused Delta can add
a new structured output layout without breaking current FCPXML references.
