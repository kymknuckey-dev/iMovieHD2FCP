# Version 1.1 Delta 1 — Migration Assistant

Delta 1 changes the GUI from a command wrapper into a guided migration experience.

## Highlights

- Persistent Migration Journey panel
- Analysis Results screen after Analyse
- In-app summary for projects, media, titles, transitions and issues
- Direct links to the analysis summary and output folder
- Preview Conversion remains optional and secondary
- Preview completion updates the results page instead of showing a dead-end dialog
- Convert Archive remains visibly available after a preview
- Existing output folders are inspected so a migration can resume
- Detailed output remains available in Activity

## Analysis totals

Delta 1 derives its summary from the existing text reports and timeline JSON files.
These totals are best-effort until the conversion engine exposes structured data directly.
