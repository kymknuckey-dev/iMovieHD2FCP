# Alpha 3 Hotfix 1

This hotfix improves workflow clarity and control.

## Fixed

- Replaced the ambiguous Dry run checkbox with a separate **Preview Conversion (Dry Run)** button.
- After a preview, the app explicitly tells the user that no files were created and that the next step is **Convert Archive**.
- Added a visible **Stop Current Operation** button while processing.
- Added confirmation before stopping a running operation or closing the app.
- Processing no longer automatically forces the Activity view.
- The main workflow remains visible while work is running.
