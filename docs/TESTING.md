# Testing

## Package tests

Install pytest in the active development environment:

```bash
python3 -m pip install pytest
python3 -m pytest
```

## Real-world regression projects

The recommended private regression corpus is:

- Small World — scrolling title, stills, soundtrack and repeated source clips.
- Disney — rendered title and varied media.
- Ring of Kerry — representative straightforward project.
- Arc de Triomphe — original title behaviour.

Do not publish family media or proprietary archive contents. Store only expected
statistics and anonymised fixtures in a public repository.
