# Troubleshooting

This guide describes the most common problems encountered when using iMovieHD2FCP and how to resolve them.

If you are new to the application, read **GETTING_STARTED.md** before using this guide.

---

# Before You Start

Many issues can be resolved by checking:

- Your original iMovie HD archive is complete.
- FFmpeg and FFprobe are installed.
- The output folder is writable.
- You are using a fresh output folder for a new conversion.
- You are running the latest version of iMovieHD2FCP.

The following command checks your installation:

```bash
imoviehd2fcp doctor
```

---

# Installation Problems

## Command not found

### Symptoms

```text
imoviehd2fcp: command not found
```

### Cause

The application has not been installed into the active Python environment.

### Solution

Activate your virtual environment.

```bash
source .venv/bin/activate
```

Reinstall.

```bash
python3 -m pip install -e .
```

---

## GUI will not start

### Symptoms

```text
The graphical application requires PySide6
```

### Solution

Install the GUI package.

```bash
python3 install_gui.py
```

# Analyse Problems

## No projects found

### Symptoms

Analysis reports zero projects.

### Possible causes

- Wrong folder selected.
- Archive is incomplete.
- Archive is not an iMovie HD archive.

### Solution

Choose the folder that directly contains your iMovie HD projects and run **Analyse Archive** again.

---

## Missing media

### Symptoms

The Archive Summary reports missing media.

### Cause

Media files have been moved or deleted.

### Solution

Restore the missing files to their original locations before converting.

---

# Conversion Problems

## Conversion stops unexpectedly

### Possible causes

- Insufficient disk space.
- Unsupported media.
- Read or write permissions.
- Damaged project.

### Solution

Check the log files.

```
Output/
└── Logs/
```

Correct the reported problem and run the conversion again.

Completed projects are reused where possible.

---

## Converted media is missing

### Cause

The source media could not be converted.

### Solution

Review:

- Archive Summary
- Project analysis report
- Conversion report

These reports identify the affected media.

---

# Event Plan Problems

## Event Plan cannot be created

### Possible causes

- Conversion has not completed.
- No project FCPXML files exist.
- Output folder is incomplete.

### Solution

Run **Convert Archive** before creating the Event Plan.

---

## My Event changes are ignored

### Cause

The Event Plan was edited but the project files were not updated.

### Solution

After saving the Event Plan, click:

**Prepare Final Cut Project Files**

This applies your Event names to each project's FCPXML file.

---

# Final Cut Pro Problems

## Projects appear in the wrong Event

### Cause

The project XML files were prepared before the Event Plan was updated.

### Solution

1. Edit the Event Plan.
2. Save the CSV.
3. Prepare Final Cut Project Files again.
4. Re-import the affected project XML.

---

## Final Cut Pro cannot import the XML

### Check

- The `.fcpxml` file exists.
- The file was generated by the current version.
- The converted media has not been moved.

If the problem persists, review the conversion reports.

---

## Media is offline

### Cause

Converted media has been moved after conversion.

### Solution

Keep each project folder intact.

Do not separate:

- Converted Media
- Project.fcpxml

---

# Existing Output Problems

## Can I continue an interrupted conversion?

Yes.

Run **Convert Archive** again.

Previously completed work is detected automatically.

---

## Can I rebuild everything?

Yes.

Use the command-line **--force** option.

---

# Performance

## Conversion is slow

Possible causes

- External USB hard drive
- NAS storage
- Large archive
- Media requiring transcoding

Using a local SSD provides the best performance.

---

# Log Files

Useful log files are stored in:

```
Output/
├── Logs/
└── _Batch Logs/
```

Always include the relevant log when reporting a problem.

---

# Reporting Problems

When reporting an issue include:

- Application version
- macOS version
- Archive size
- Number of projects
- Relevant log file
- Steps to reproduce the problem

Screenshots are also helpful.

---

# Still Need Help?

Before opening a GitHub issue:

1. Run:

```bash
imoviehd2fcp doctor
```

2. Read:

- GETTING_STARTED.md
- USER_GUIDE.md
- FAQ.md

3. Include the relevant log files and reports with your issue.

This information greatly improves the chances of diagnosing the problem quickly.
